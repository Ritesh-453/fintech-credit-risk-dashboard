# Credit Risk Intelligence Dashboard

## What it does
- Analyzes 1.37M real LendingClub loans to show what separates good lending from bad
- Default rate by grade, DTI, income, state and loan purpose
- Interactive filters applied live across all views
- Key finding: loans with DTI 30+ default at 31%, nearly double the lowest segment

## Tech used
- **Data:** Python, pandas, MySQL, SQL
- **BI:** Power BI (DAX, slicers)
- **Web app:** Streamlit, Plotly
- **Deployment:** Streamlit Community Cloud
